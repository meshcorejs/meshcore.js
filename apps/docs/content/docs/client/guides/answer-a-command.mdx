## What happens

The file is picked up at login because it sits in `commands/` and exports the builder. A missing name or
handler stops the bot at startup with a clear message instead of failing later on the air.

In a DM the trigger is `/heard`. On a channel it is `@ClubBot heard`, with the name the radio advertises.
This rule is the same for every bot and cannot be changed.

`ctx.reply()` answers where the command came from. The `MessageBuilder` keeps the answer under the 160-byte
limit of a radio message and cuts the list when it is too long.
