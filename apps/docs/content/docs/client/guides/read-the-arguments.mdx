`/heard 6 repeater` lists the repeaters heard in the last six hours. Both values are optional and have a
default.

## What happens

Each `add*Arg` call declares one argument. `ctx.args` is typed from these calls, so `hours` is a
`number` and `kind` is `'chat' | 'repeater'` without a cast.

A value outside the range, or a kind that is not in the list, never reaches the handler. The bot answers
with the usage line instead.

Values are split on spaces. Double quotes keep a value with spaces together. A string argument with
`setRest()` takes the rest of the line.
