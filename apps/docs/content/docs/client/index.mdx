`@meshcorejs/client` is the bot framework for [MeshCore](https://github.com/meshcore-dev/MeshCore) radios
running the **Companion Radio** firmware. A `Client` logs into the radio and keeps its contacts and channels
in cache. Everything the bot does is declared with builders, the way [discord.js](https://discord.js.org)
bots are. It is the only package a bot installs.

## Requirements

- A MeshCore node running the **Companion Radio** firmware, protocol version 3 or newer.
- Node.js 20 or newer to run bots.
- Serial needs `serialport`. BLE needs `@abandonware/noble`. TCP needs nothing.
